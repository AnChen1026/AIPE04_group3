# 課程也可以產生限時綁定碼

補充 [0004](0004-course-binding-code.md)。原本只有「一人一碼」：老師在接洽對話裡替一位學生發綁定碼。老師希望在課程頁直接拿到一組碼，貼給好幾位學生（例如團體課或實體招生），不用每個人先洽詢。

所以每門已發布課程可以另外產生一組**限時綁定碼**：有效時間由老師選（1、24、72 或 168 小時），期限內任何拿到碼的學生都能加入這門課，可以重複使用。一門課同時只有一組，重發或停用後舊碼立刻失效。學生用限時碼加入時，系統同時開好他和老師的接洽對話，之後照常聯絡。

一人一碼仍然保留，老師要只收某位學生時照舊用它。綁定前不開放教學功能、解除綁定的規則都不變；被解除綁定的學生若還拿得到有效的限時碼，可以再加入，老師要擋人時應停用或重發限時碼。
