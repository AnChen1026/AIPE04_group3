# 可上課時段：學生點選後仍走課務申請

老師希望在課表上開放幾段可以上課的時間，讓已綁定的學生直接點選，不用每次在聊天室來回約。

學生點選時段時，不直接寫入正式課表，而是送出一筆約課的課務申請（`change_requests`，記下來源 `availability_slot_id`），同時把時段標成「待完成約課」保留給他。老師按「完成約課」才建立 `lesson_sessions`，拒絕或取消預約時時段回到可預約。這樣維持 [課務申請](../../GLOSSARY.md) 的規則：老師同意前正式課表不變，也讓老師在開放時段後仍能挑學生。

同一個時段只能被一位學生保留：預約時用「只有狀態還是 open 才改成 held」的單筆更新，兩人同時按時，後到的交易會等前一筆結束再判斷、更新到 0 筆而回 409，不需要另外上鎖或排隊。

看得到、能預約的範圍跟綁定一致（[0004](0004-course-binding-code.md)、[0008](0008-course-join-code.md)）：學生透過自己已綁定的課查詢那位老師的時段，未綁定或解除綁定的學生看不到也不能預約；時段只屬於一位老師，不能透過別位老師的課看到或預約（[0002](0002-isolate-records-by-teacher-and-course.md)）。

老師和學生私下約好時，老師可以把時段（或空格）直接排給已綁定的學生，這是老師自己的決定，不需要再送申請。
