# 每週固定時間與只能從時段選的課務申請

老師不想每格手動拉時段，也希望學生不要提出老師根本沒空的時間。所以老師可以設定 [每週可上課時間](../../GLOSSARY.md) 和學生的 [固定上課時間](../../GLOSSARY.md)，學生的約課與調課只能從 [可上課時段](../../GLOSSARY.md) 選；想要其他時間請自行聯繫老師，後端不再接受學生自己填的時間。這延伸 [0009](0009-teacher-availability-slots.md)：仍然走課務申請，老師同意前正式課表不變。

**規則與實際資料分開，往後維持 8 週。** 規則存在 `weekly_availability`、`recurring_lessons`，實際的時段與課堂仍是 `availability_slots`、`lesson_sessions`，其他功能不用知道規則的存在。規則記下 `generated_through`，有人看課表時才往後補，不需要排程工作；只補新的日子，所以老師刪掉的單一時段、學生請假的那堂不會被補回來。時間以台灣時間的星期與當天第幾分鐘儲存，台灣沒有日光節約，固定用 UTC+8 換算。

**時段可以切開。** 開放時段可能很長（18:00-21:00），學生在其中選開始時間，選走的部分成為保留的時段，前後留成可預約；拒絕或取消時併回相鄰的可預約時段，之後才放得下較長的課。切時段前鎖住那一筆，取代 0009 的單筆條件更新，兩人同時選時後到的看到的就不是可預約，回 409。

**調課沿用原本那堂的長度；學生新約的課選 60 或 90 分鐘。** 其他長度由老師決定：老師直接排課與固定上課時間可以設定任何 15 分鐘為單位的長度。系統不強制課與課之間留空檔，要留給換地點的時間由老師自己排。

**改動規則時已排的課優先。** 改每週可上課時間只重算還沒人預約的固定時段。學生的課蓋到開放時段時，開放時段讓出來；碰到別的課或待確認的預約時，只跳過那一週並列給老師看。兩個固定上課時間彼此重疊則直接擋下，因為每週都會撞，跳過解決不了。改或停用固定上課時間時，已排的課不自動變動，由老師勾選要移動或取消哪幾堂，避免學生的課在沒確認下被改。
