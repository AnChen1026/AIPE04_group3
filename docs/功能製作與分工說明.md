# 鋼琴教學管理與課程推廣平台－功能製作與分工

版本 V1.2；更新 2026-09-30；配套：PRD、SRS、User Flow 與資料表設計 V1.2。

## 1. 已定方向

網站內整合老師及學生雙端，移除 LINE，樂器只做鋼琴。首頁提供公開課程、智能推薦與初步程度辨識；註冊學生後可站內洽詢。

教學端保留課表、學生、課務申請、聊天、MIDI 作業、錄音回饋、教材及 AI 測驗。新增老師課前練習摘要，支持老師安排本次教學。

已確認的界線：錄完送出後快速回饋；必要參考答案為 MIDI；先驗證短曲、單音或簡單雙手、無踏板；課前摘要以「上次課後至本次課前」為期間，老師開啟課堂頁時產生／更新。

## 4. 必須對齊的實作規則

- 推薦後先洽詢，洽詢不是報名；正式師生雙向同意後才可修課與使用教學資料。
- 公開課程發布狀態與內部教學資料分開，不能因公開課程而公開學生資料。
- 兩端共用同一 users、course、enrollment、assignment、submission、session ID。
- 練習處理流程：保存錄音 → 音訊事件 → MIDI 對齊 → 規則評分 → LLM 文字。
- 音正確但拍不齊要分開反映；分析失敗不能顯示 0 分，LLM 失敗保留分析結果。
- 摘要流程：老師權限 → 本次課堂學生 → 同修課前堂結束至本次開始／當下 → 統計與可靠差異 → 自然語言摘要。
- 摘要的提交次數只是平台紀錄；不同曲目不直接比较總分；有新結果或課堂改期要更新。
- 測驗 AI 只產草稿，老師審核後發布；標準答案批改由後端控制。
- 課務異動由老師確認且最後檢查衝突後生效；不直接由 AI 改課表。

## 5. 建議整合順序

| 階段 | 工作 | 驗證結果 |
| --- | --- | --- |
| 1 | 登入、工作室範圍、師生關係與基本課程 | 身份及資料權限一致 |
| 2 | 公開課程、推薦／程度、站內洽詢 | 找課到加入老師的完整流程 |
| 3 | 課表／申請、共用檔案與 MIDI 作業 | 老師排課／出作業、學生送申請與錄音 |
| 4 | 音訊分析／評分／學生回饋 | 固定短曲可回傳可追溯結果 |
| 5 | 老師課前摘要 | 正確窗口、來源、無紀錄與更新處理 |
| 6 | 教材、AI 測驗、聊天及整合驗收 | 學生完成作答、訊息互通、越權被拒絕 |

聊天與教材可在身份／修課完成後平行開發；表列順序為整合依賴，不是另指派人力。

## 6. 剩餘工程決策

首頁及各 AI／共用服務負責人、Google 登入、教材格式、錄音長度上限、固定測試曲目、評分容許誤差、回饋延遲目標、約課／異動期限、重考次數及資料保留政策待定。

這些以可設定參數或待指派工作記錄；不能用舊分工猜測成已決議。現有程式碼與 Migration 未提供，文件更新不代表功能已完成。
