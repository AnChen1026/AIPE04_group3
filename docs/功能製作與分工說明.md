# 鋼琴教學管理與課程推廣平台－功能製作與分工

版本 V1.3；更新 2026-10-12；配套：PRD、SRS、User Flow V1.3。

## 1. 已定方向

網站只做鋼琴。正式畫面使用 Vue，後端使用 FastAPI，資料庫使用 PostgreSQL。登入沿用 Session Cookie，不改成 JWT，也不改成 Next.js。

已完成註冊、登入、角色、基本資料與老師審核。本輪繼續做課程、首頁推薦、接洽對話、綁定碼、課表、練習錄音、練習回饋與課前摘要。

教材與 AI 測驗本輪不做。

## 3. 功能與資料

資料表名稱由 Ollie 與禹銨對齊，不沿用舊草案裡的工作室表。本輪要能保存：

| 功能 | 老師 | 學生／訪客 |
| --- | --- | --- |
| 課程 | 新增、發布、封存，並指定一份參考 MIDI | 只看已發布課程 |
| 首頁推薦 | 填程度、風格、線上或實體、地區、單堂價格、時段 | 訪客描述需求，最多追問兩題 |
| 接洽對話 | 回覆，並貼上綁定碼 | 按洽詢即建立對話 |
| 綁定 | 產生與解除自己課程的綁定 | 輸入綁定碼後進入該課 |
| 課表 | 同意或拒絕約課、請假、調課 | 綁定後提出申請 |
| 練習 | 看自己課程的練習回饋與課前摘要 | 錄音或上傳音檔，看該次練習回饋 |

## 4. 必須對齊的規則

- 洽詢只建立接洽對話。輸入綁定碼後才使用課表、錄音、練習回饋、課前摘要與課程管理。
- 綁定前後是同一段對話。
- 綁定碼只屬於一位學生的一門課。
- 練習回饋與課前摘要分開保存。
- 找課程度不使用練習分數。
- 老師只能讀取自己課程的資料。
- 新 API 都有簡單測試頁。正式使用者只走 Vue。

## 5. 建議順序

| 順序 | 工作 | 可以開始的條件 |
| --- | --- | --- |
| 1 | 資料表與首頁推薦、使用流程、後端 API | 都可以直接開始 |
| 2 | Vue 正式頁 | 使用流程與 API 可對接 |
| 3 | Docker 部署 Vue 與 FastAPI | API 與 Vue 可運行 |
| 之後 | 教材與 AI 測驗 | 本輪不做 |

## 6. 尚未定的參數

錄音長度上限、評分容許誤差、回饋延遲秒數與資料保留期限尚未定。這些參數不改變本輪流程。
