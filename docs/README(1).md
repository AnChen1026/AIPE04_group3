| 主要對象 | 音樂老師、音樂工作室、音樂學生 |

## 1. 專案說明

本專案是一套以音樂教學為核心的網頁平台，整合公開課程推薦、老師課務管理、學生學習入口、站內即時聊天，以及 AI 音樂學習輔助。

V1.2 不串接 LINE。老師與學生皆透過網站註冊及登入，並依註冊時選定的單一角色進入各自頁面。

## 2. V1.2 核心功能

- 公開首頁課程瀏覽、條件篩選及 AI 課程推薦。
- 註冊時選擇老師或學生；MVP 不支援同帳號切換角色。
- 老師後台管理課程、學生、課表、請假／調課申請、教材、測驗與練習任務。
- 學生頁面查看課程與課表、提出請假／調課、與老師聊天、完成測驗及鋼琴練習。
- 師生可透過課程洽詢，或老師邀請碼／邀請連結建立關係。
- 站內一對一即時文字聊天、未讀數及聊天紀錄。
- 老師上傳教材，由 AI 產生選擇題／是非題；老師審核發布後由系統自動批改。
- 老師上傳樂譜圖片或參考音檔，學生以瀏覽器麥克風錄音，系統提供小節級、概略且鼓勵性的練習回饋。

## 3. 明確不在 V1.2 MVP

- LINE Messaging API、LINE Login 或 LINE OA。
- 同一帳號同時具有老師與學生角色。
- 線上金流、電子發票、自動對帳與退款。
- 群組聊天、語音通話、視訊課程與聊天附件。
- AI 自動發布測驗，不經老師審核。
- AI 取代老師進行正式音樂檢定或宣稱精密音準診斷。
- 根據登入學生歷史建立長期個人化推薦檔案；此項保留至後續版本。

## 4. 技術方向

| 層級 | 技術方向 |
| --- | --- |
| Frontend | Next.js + TypeScript |
| Backend | FastAPI |
| Database | PostgreSQL |
| ORM / Migration | SQLAlchemy 2.0 + Alembic |
| 即時聊天 | WebSocket；斷線後以 REST 補抓歷史訊息 |
| AI | OpenAI API + Pydantic Structured Output |
| 檔案 | 物件儲存；資料庫只存 metadata 與 storage key |
| Container | Docker + Docker Compose |
| Deployment | Vercel（前端）＋ Cloud Run（後端，規劃） |

> 音訊辨識、樂譜圖片辨識與背景工作技術尚需原型驗證，不在本文件中指定未經團隊確認的套件。
