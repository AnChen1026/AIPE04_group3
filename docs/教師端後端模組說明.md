# 教師端後端檔案位置

教師端程式已依照共用後端架構，放在 `backend/` 的對應資料夾。

模板預設位於專案根目錄 `templates/teacher/dashboard.html`。上傳資料夾預設位於專案根目錄 `uploads/`。

- `backend/models/`：教師端資料庫 ORM 模型。
- `backend/schemas/`：教師端 Pydantic 請求格式。
- `backend/routers/teacher_*.py`：教師端 API，網址路徑不變。
- `backend/dependencies/teacher.py`：登入教師與審核驗證。
- `backend/services/teacher_sync.py`：共用 User 同步教師 profile 的事件。
- `backend/core/uploads.py`：上傳目錄。
