# 教師端後端檔案位置

教師端程式已依照共用後端架構，放在 `backend/` 的對應資料夾。完整的 Router 一覽見 `backend/README.md`。

畫面都在 Vue（`frontend/`），後端不再提供模板頁。本機上傳資料夾預設位於專案根目錄 `uploads/`；設定 `STORAGE_BACKEND=supabase` 時，檔案改放 Supabase 私有 bucket。

- `backend/models/`：資料庫 ORM 模型（老師資料在 `teacher.py`，工作室在 `studio.py`，作業在 `assignment.py`，課程、課表、練習等在 `student.py`）。
- `backend/schemas/teacher.py`：教師端 Pydantic 請求與回應格式。
- `backend/routers/teacher_*.py`：教師端 API。作業 API 在 `backend/routers/assignments.py`，和學生端共用一個檔案。
- `backend/dependencies/teacher.py`：登入教師與審核驗證。
- `backend/services/teacher_sync.py`：共用 User 同步教師 profile 的事件。
- `backend/services/availability.py`、`backend/services/weekly_schedule.py`：可上課時段、每週可上課時間與固定上課時間。
- `backend/core/uploads.py`：本機上傳目錄。
- `backend/core/storage.py`：存檔、讀檔與刪檔，本機與 Supabase 共用同一組函式。
