# 登入註冊邏輯說明

這份文件說明 **目前程式實際怎麼跑**，給組員對接老師端／學生端使用。  
不是產品規格書；規格仍以 PRD、SRS、功能製作與分工為準。

啟動方式：專案根目錄執行 `python -m backend.main`（API 在 `http://127.0.0.1:8000`），畫面另外啟動 Vue（`http://localhost:3000`）。

---

## 1. 一句話

使用者在 Vue 先選學生或老師 → 用 Email 密碼或 Google 建立帳號 → 登入後 Session 記住 `user_id` → Vue 依 `role` 與老師申請狀態進入對應頁面。後端只提供 API，不回 HTML。

| 身份 | 註冊後 | 登入後去哪 |
| --- | --- | --- |
| 學生 | `role=student`，註冊後自動登入 | `/student` |
| 老師 | `role=teacher`，申請 `pending`，`is_active=False` | `/teacher`（只顯示審核中） |
| 老師（Google，還沒申請資料） | `role=teacher`，沒有申請 | `/teacher`（先補填申請表） |
| 老師（已核准） | 申請 `approved`，`is_active=True` | `/teacher`（完整老師後台） |
| 老師（已駁回） | 申請 `rejected`，不能用老師功能 | `/teacher`（只顯示未通過） |
| 管理員 | `.env` 的 `ADMIN_EMAIL` 啟動時建立 | `/admin` |

管理員核准後才把老師 `is_active` 設成 True，並維持 `role=teacher`。

---

## 2. 請求怎麼往下走

```text
瀏覽器（Vue：frontend/src/views/auth、admin、student、teacher）
    → backend/main.py（掛 Session、載入 router）
        → routers/auth.py、admin.py、student*.py 或 teacher_*.py（路由）
            → services/（規則：註冊、登入、審核、Google）
                → repositories/（查詢／寫入）
                    → models/（users、teacher_applications、auth_identities）
                        → PostgreSQL
```

密碼不會明文進資料庫。`backend/core/security.py` 用 Argon2 做成 `password_hash`。  
登入成功後只把 `user_id` 放進 Cookie Session，之後每次 API 用 `get_current_user()` 找回使用者。

登入註冊的 API 都在 `/api/auth/...`；只有 Google 驗證回來的 `/auth/google/callback` 不在 `/api` 底下，因為那是 Google 直接把瀏覽器導回來的網址。

---

## 3. 畫面流程

畫面都在 Vue（`frontend/src/views/auth/`），括號裡是 Vue 呼叫的 API。

### 學生註冊

```text
/signup 選「學生」         Email、密碼、基本資料
送出                       （POST /api/auth/register）
自動登入                   （POST /api/auth/login）→ /student
```

從課程詳情按「註冊並與老師接洽」來的，註冊完會直接打開和這位老師的聊天。

### 老師註冊（Email）

```text
/signup 選「老師」         基本資料 + 教學項目／經歷／簡介（證明文件選填）
送出                       （POST /api/auth/register/teacher，FormData）建立老師 + pending 申請
/login 登入                → /teacher，只顯示「審核中」
管理員核准後               is_active=True，重新整理 /teacher 就是完整後台
```

### Google 註冊與登入

```text
/signup 或 /login 按 Google （GET /api/auth/google-url）拿到 Google 網址，瀏覽器跳過去
Google 驗證完              Google 把瀏覽器導回 GET /auth/google/callback
後端建立或找出帳號、寫 Session，再導回 Vue：
  學生 → /student、老師 → /teacher、管理員 → /admin
  失敗 → /login?error=原因，登入頁顯示原因
```

用 Google 建立的老師還沒有申請資料。進 `/teacher` 會先看到補填表單（`POST /api/auth/teacher-application`，FormData），送出後變成「審核中」。

還沒註冊過的 Google 帳號不能從登入頁直接建號，要先走註冊並選身份。

### 登入／登出／基本資料

```text
/login                     （POST /api/auth/login）失敗不寫 Session
登出                       （POST /api/auth/logout）
學生 /student/profile       （PATCH /api/auth/me）
老師 /teacher/profile/edit  （POST /teacher/profile、POST /teacher/photo）
```

### 管理員審核老師

```text
/admin                     總覽
/admin/applications        申請列表、核准、駁回、下載證明文件
/admin/teachers、/admin/students   老師與學生名單
```

本機測試管理員：`.env` 設 `ADMIN_EMAIL`、`ADMIN_PASSWORD`，啟動時自動建立（不要把 `.env` 推上 Git）。

## 4. 路由一覽

程式在 `backend/routers/`，由 `backend/main.py` 掛上登入、管理員、學生及 `teacher_*.py` 路由。

後端只有 JSON API，畫面都在 Vue。

Vue 的請求都從 `frontend/src/api/http.ts` 送出，會帶上 Cookie。本機開發時 Vue 走 `/backend` 代理，瀏覽器視為同一個網站。若 Vue 與 FastAPI 不同網址，本機 CORS 必須允許該 Vue 開發網址並開啟 credentials。目前已允許 `http://localhost:3000` 與 `http://127.0.0.1:3000`。

瀏覽器也可開 `http://127.0.0.1:8000/docs` 看自動產生的 API 說明。

| 方法 | 路徑 | 做什麼 |
| --- | --- | --- |
| POST | `/api/auth/register` | 建立學生（JSON） |
| POST | `/api/auth/register/teacher` | 建立老師（FormData，證明文件選填） |
| POST | `/api/auth/login` | 登入並寫 Session |
| POST | `/api/auth/logout` | 登出 |
| GET | `/api/auth/me` | 目前登入者；老師多 `application_status` |
| PATCH | `/api/auth/me` | 更新基本資料 |
| GET | `/api/auth/teacher-application` | 目前老師的申請 |
| POST | `/api/auth/teacher-application` | Google 老師補申請（FormData） |
| GET | `/api/auth/google-url` | 回傳 Google 導向網址；未設定則 503 |
| GET | `/auth/google/callback` | Google 導回來的網址：登入或註冊後導回 Vue，失敗導回 `/login?error=` |
| GET | `/api/admin/teacher-applications` | 管理員看全部申請 |
| POST | `/api/admin/teacher-applications/{id}/approve` | 核准 |
| POST | `/api/admin/teacher-applications/{id}/reject` | 駁回 |
| GET | `/api/admin/teacher-applications/{id}/proof` | 下載證明文件 |
| GET | `/api/admin/teachers`、`/api/admin/students` | 老師與學生名單 |

`UserResponse.application_status`：學生／管理員為 `null`；老師為 `pending`、`approved`、`rejected`，還沒送申請則為 `null`。

共用權限輔助函式在 `backend/dependencies/common.py`，老師端權限在 `backend/dependencies/teacher.py`：

- `get_session_user`：Cookie 有 `user_id` 才查出人
- `get_current_user`：沒登入就 401
- `get_current_admin`：必須是已啟用的 admin
- `require_roles("teacher")`：要已啟用且角色符合

老師功能以 `is_active=True` 且申請 `approved` 為準。

## 5. 資料表

Alembic 檔案在 `backend/alembic/versions/`。本機空資料庫請執行：

```bash
alembic -c backend/alembic.ini upgrade head
```

| 表 | 用途 |
| --- | --- |
| `users` | Email、密碼雜湊、姓名、電話、生日、性別、`role`、`is_active`、`auth_provider` |
| `teacher_applications` | 教學項目、經歷、簡介、選填證明文件、`pending`／`approved`／`rejected` |
| `auth_identities` | Google 的 `provider` + `provider_subject`，對應 `users.id` |
| `teacher_profiles` | 老師端完整資料；由老師模組同步建立 |
| `courses` | 老師課程 |
| `inquiry_conversations`、`conversation_messages` | 學生接洽與訊息 |
| `course_bindings`、`binding_codes` | 學生與課程的綁定 |
| `lesson_sessions`、`change_requests` | 課表與課務申請 |
| `practice_recordings`、`practice_feedbacks` | 練習錄音與回饋 |
| `lesson_preparation_summaries` | 課前摘要 |

`role` 只能是 `student`、`teacher`、`admin`。公開註冊不能當 admin。  
Google-only 帳號的 `password_hash` 可為空，不能用 Email 密碼登入。

證明文件若有上傳，存在專案 `uploads/teacher_proofs/`（已 gitignore）。

`teacher_profiles` 已由老師端 Model 建立；目前仍沒有獨立的 `student_profiles`，學生基本資料先使用 `users`。所有資料表都由 Alembic Migration 建立（目前到 `009`），網站啟動時不再自動建表。

## 6. 用到的工具與套件

| 用途 | 工具 | 程式位置 |
| --- | --- | --- |
| 網站與 API | FastAPI、Uvicorn | `backend/main.py` |
| 網頁畫面 | Vue | `frontend/` |
| 記住登入 | Starlette `SessionMiddleware`、`itsdangerous` | `backend/main.py` |
| 檔案上傳 | `python-multipart` | 老師註冊、補申請、照片與課程圖片 |
| 檢查 Email 格式 | `email-validator`、Pydantic `EmailStr` | `auth.py`、`schemas/user.py` |
| 密碼雜湊 | `argon2-cffi` | `backend/core/security.py` |
| ORM／資料庫 | SQLAlchemy 2、`psycopg`、PostgreSQL 16 | `backend/core/database.py` |
| 建表 | Alembic | `alembic/` |
| Google 驗證 | 標準庫 `urllib` 呼叫 Google OAuth | `backend/services/google_auth.py` |

`.env`（不要提交 Git）常用變數：

| 變數 | 用途 |
| --- | --- |
| `DATABASE_URL` | PostgreSQL 連線，例如 `postgresql+psycopg://aipe04:aipe04@localhost:5432/aipe04` |
| `SESSION_SECRET_KEY` | 簽署 Session Cookie |
| `ADMIN_EMAIL`、`ADMIN_PASSWORD` | 本機測試管理員 |
| `GOOGLE_CLIENT_ID`、`GOOGLE_CLIENT_SECRET`、`GOOGLE_REDIRECT_URI` | Google 登入；未設定時登入頁會顯示無法使用 |
| `FRONTEND_URL` | Google 驗證完導回的 Vue 網址；沒設定時導向站內路徑 |

Google Redirect URI 本機請設：`http://localhost:3000/backend/auth/google/callback`（經過 Vue 的 /backend 代理，驗證完回到 Vue 頁面）

本機 PostgreSQL 可用專案根目錄：

```bash
docker compose up -d postgres
```

## 7. 對接時請這樣判斷身份

1. 用 `GET /api/auth/me` 取得使用者。
2. `role == "student"` 且 `is_active == true` → 一律可進學生工作區；未綁定課程時仍能看介面，但不能使用課表、作業／練習等綁定後功能。
3. `role == "teacher"` 且 `is_active == true` → 老師工作區。
4. `role == "teacher"` 且 `is_active == false` → 依 `application_status` 顯示補填申請（`null`）、審核中或駁回，不要開放課程、學生、作業。
5. 不要讓前端自己改 `role`；後端以資料庫為準。
