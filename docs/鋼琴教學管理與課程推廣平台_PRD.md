# 鋼琴教學管理與課程推廣平台 PRD

| 項目 | 內容 |
| --- | --- |
| 版本／日期 | V1.4／2026-11-01 更新進度 |
| 階段 | 找課、接洽、課表、作業與練習回饋已有 API 與畫面；AI 測驗尚未完成 |
| 主要對象 | 鋼琴老師、鋼琴學生、未註冊訪客 |

本版整合 2026-10-12 的流程決策、[Issue #24](https://github.com/AnChen1026/melo-piano-platform/issues/24) 與 [Issue #25](https://github.com/AnChen1026/melo-piano-platform/issues/25)。與舊版文件衝突時，以本文件為準。

## 1. 專題方向

建立鋼琴課程推廣與教學練習網站。訪客在首頁描述想學的內容，看到已發布的真實鋼琴課。學生註冊後先和老師接洽，輸入綁定碼後才使用課表與練習。老師只看見自己課程裡的學習紀錄。

## 2. 現況與範圍

| 狀態 | 內容 |
| --- | --- |
| 已有 API 與畫面 | 註冊、登入、登出、單一角色、基本資料、修改密碼、忘記密碼（由管理員重設，不寄信）、老師申請與平台管理員審核。工作室、課程發布、全部課程頁、首頁推薦、接洽對話、綁定碼、限時綁定碼、課表、可上課時段、課務申請、演奏作業、參考 MIDI、練習錄音、音訊評分、練習回饋、對照樂譜、課前摘要、管理員對話。管理員由 `.env` 建立，不能公開註冊。 |
| 部署 | Docker Compose 可同時啟動 PostgreSQL、FastAPI 與 Vue。共用測試站的設定在 `render.yaml`、`deploy/`，見 `docs/deployment.md`。 |
| 尚未完成 | AI 測驗（只有教材上傳與測驗列表的原型 API）、題庫作業、獨立搜尋頁與課程詳情頁。 |
| 不做 | 完整教材庫、Email 認證、把 Session 改成 JWT、把網站改成 Next.js。 |

## 3. 使用者問題與產品目標

- 訪客需要看到真實鋼琴課，而不是系統編出來的課程。
- 學生需要先接洽，確定上課後才錄音並看到該次結果。
- 老師需要在課前看到這段期間的練習彙整，而且看不到其他老師的學生資料。

核心教學流程是：找課 → 洽詢 → 綁定碼 → 課表與練習 → 練習回饋 → 課前摘要。AI 測驗是綁定後的學習功能。

## 4. 角色與權限

| 角色 | 可以做的事 |
| --- | --- |
| 訪客 | 使用首頁推薦、看已發布課程。洽詢前要註冊或登入。 |
| 未綁定學生 | 可直接進學生介面並對已發布課程建立接洽對話；可同時接洽多門課，但不能使用課表與作業／練習。 |
| 已綁定學生 | 使用該課的對話、課表、課務申請、作業與錄音，並查看自己的練習回饋。 |
| 老師 | 管理自己的工作室、課程與作業（含參考 MIDI），在接洽對話貼上綁定碼或產生限時綁定碼，處理自己課程的課表、錄音、練習回饋與課前摘要，並可解除自己課程的綁定。 |
| 平台管理員 | 老師審核、師生名單、處理忘記密碼申請，以及和老師、學生對話。沒有課程或練習管理功能。 |

未綁定學生不能使用課表、錄音、練習回饋、課前摘要與該課課程管理。老師不能查看其他老師的學生、錄音、練習回饋、課前摘要與訊息。學生只能查看自己的紀錄。

## 5. 功能

| ID | 功能 | 行為 |
| --- | --- | --- |
| F01 | 課程 | 老師新增課程，填找課程度、風格、線上或實體、地區、單堂價格、時段。狀態為草稿、已發布、已封存。只有已發布課程可被推薦與洽詢。 |
| F02 | 首頁推薦 | 訪客免登入。整次最多追問兩題。找課程度只來自自述：入門、初階、中階、進階、不確定。只回傳已發布鋼琴課。未知條件不視為符合。不編造課程。 |
| F03 | 登入 | 沿用已完成的註冊、登入、登出、基本資料與角色。不重做。 |
| F04 | 接洽與綁定碼 | 學生對已發布課程按洽詢即建立接洽對話，不另填申請表。老師把只屬於該學生與該課的綁定碼貼進對話，也可以替已發布課程產生限時綁定碼。學生輸入後進入該課。同一段對話繼續保留。 |
| F05 | 課表與課務申請 | 老師設定可上課時段、每週可上課時間與固定上課時間。學生的約課與調課只能從可上課時段選，也可請假。老師同意且時段未被占用前，正式課表不變。 |
| F06 | 接洽對話 | 綁定前後是同一段對話。保留歷史與未讀。人留在對話頁時看得到新訊息。 |
| F07 | 作業、練習錄音與練習回饋 | 老師替已綁定學生發演奏作業，附參考 MIDI 與教材。學生以瀏覽器錄音為主，沒有麥克風可上傳音檔。每一筆錄音有自己的音高、節奏、文字說明與對照樂譜。作業沒有 MIDI 時用課程的參考 MIDI。 |
| F08 | 課前摘要 | 同一學生、同一課程，範圍是上一堂結束後到這一堂開始前。不取代練習回饋，也不合成正式程度或找課程度。 |
| F09 | 畫面與 API 驗證 | 使用者畫面只做 Vue。新 API 不另做測試頁，改用 FastAPI 自動產生的 `/docs` 與 `tests/` 自動測試驗證。 |
| F10 | 部署 | Docker 可同時啟動 Vue 與 FastAPI。`.env`、金鑰與密碼不放進映像檔或 Git。 |
| F11 | AI 測驗（尚未完成） | 老師提供出題來源教材，AI 產生選擇題與是非題草稿。老師審核後才能發布；學生作答中看不到答案，交卷後由系統批改並顯示分數。 |

## 6. AI 與後端各做什麼

| 應用 | AI／模型負責 | 後端負責 |
| --- | --- | --- |
| 首頁推薦 | 預設不用模型。設定共用本機模型後，模型協助整理條件與追問，並做語意排序 | 規則解析與驗證條件、限制追問次數、只篩已發布課程、由實際欄位組成推薦理由 |
| 音訊評分 | 把音檔轉成音符事件 | 與該課參考 MIDI 對齊，分開計算音高與節奏 |
| 練習回饋 | 依該次評分結果產生文字 | 保存該筆結果。辨識失敗不顯示成 0 分 |
| 課前摘要 | 把該期間的練習整理成老師可讀的摘要 | 限定同一學生、同一課程與時間範圍 |
| AI 測驗 | 只依老師提供的出題來源教材產生選擇題與是非題草稿 | 保存草稿、提供老師審核與發布、作答中隱藏答案、交卷後批改 |

AI 不決定誰可以看資料、不直接修改課表，也不能自行發布測驗。練習分數不改變找課程度。

## 7. 關鍵規則

1. 只提供鋼琴課程。
2. 找課程度分為入門、初階、中階、進階、不確定，只來自訪客自述與最多兩次追問。
3. 未知條件保持未知，不假裝符合。
4. 沒有符合的已發布課程時明確說明，不編造課程。
5. 按洽詢只建立接洽對話。輸入綁定碼後才取得該課的教學功能。
6. 綁定碼只給一位學生的一門課，不能轉給別人，也不寄信或簡訊。限時綁定碼屬於一門課，期限內可重複使用，同時只有一組。
7. 老師可解除自己課程的綁定。該課教學功能關閉，接洽對話保留，其他課程不受影響。
8. 課務申請在老師同意且時段空著之前，不改變正式課表。
9. 練習回饋針對作業的參考 MIDI；作業沒有附時才用課程的參考 MIDI。
10. 練習回饋描述一筆錄音。課前摘要描述上一堂結束到這一堂開始前的彙整。
11. 沒有平台練習紀錄時，課前摘要要這樣說明，不推論成「學生沒有練習」。
12. 公開課程頁不顯示個別學生的錄音、練習回饋或課前摘要。
13. AI 測驗題目必須來自老師提供的內容，並經老師審核後才可發布。
14. 作答期間不回傳正確答案或解析；學生只能查看自己的作答結果。

## 8. 技術方向

- Frontend：Vue
- Backend：FastAPI
- Database：PostgreSQL
- ORM／Migration：SQLAlchemy、Alembic
- 登入：既有 Session Cookie
- 部署：本機 Docker Compose；共用測試站 Render 加 Supabase

Vue 呼叫 JSON API 並帶上 Cookie。開發時走 Vite 的 `/backend` 代理，瀏覽器視為同一個網站。

## 9. 目前不包含

完整教材庫、Email 認證、登入限流、JWT、Next.js、LINE、金流、以練習分數產生正式程度。

AI 測驗只納入「老師提供出題來源教材」所需的最小流程，不代表建立完整教材管理系統。

V1.2 寫過的「雙方另填加入申請」「課程 paused 狀態」「綁定後另開聊天室」不採用。

## 10. 驗收

| 驗收 | 判準 |
| --- | --- |
| 推薦 | 不生成不存在的課程；最多追問兩題；未知條件不假裝符合 |
| 綁定 | 綁定前只能接洽；綁定碼只進入對應課程；解除後該課教學功能關閉 |
| 權限 | 改學生、老師或課程識別資料，不能看到別人的錄音、回饋、摘要或訊息 |
| 課表 | 老師尚未同意或時段已被占用時，正式課表不變 |
| 練習 | 學生可錄音或上傳音檔，並看到該次音高、節奏與文字 |
| 課前摘要 | 只含同一學生、同一課程、上一堂結束到這一堂開始前的資料 |
| AI 測驗 | AI 只產生草稿；老師審核後才發布；作答中不顯示答案；交卷後顯示批改分數 |
| 畫面 | 流程都走 Vue；新 API 有自動測試 |

AI 測驗的驗收項目要等功能完成後才能執行。

錄音長度上限、評分容許誤差與回饋延遲秒數仍待實測後再定，不改變上面的流程。
