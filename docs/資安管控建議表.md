# 鋼琴教學管理與課程推廣平台－資安管控建議表

更新 2026-11-01。產品規則以 PRD 為準。下表是應有的控制，不代表都已實作；已確認的現況見第 2 節。

## 1. 控制表

| 項目 | 風險 | 控制 | 優先 |
| --- | --- | --- | --- |
| 登入與角色 | 身份冒用／越權 | 密碼雜湊、登入限流、後端角色判斷、登出與登入失效設計 | 必做 |
| 老師與課程範圍 | 讀到別位老師或學生資料 | 每次查詢同時驗證老師、課程與目前使用者 | 必做 |
| 公開課程 | 公開私人學生紀錄 | 公開 API 只用公開欄位；錄音、成績、摘要及聊天不公開 | 必做 |
| 接洽對話 | 未綁定就取得教學資料 | 綁定前只能使用該課對話，不能讀課表、錄音、回饋與摘要 | 必做 |
| 綁定碼 | 一碼轉給別人或加到別門課 | 一碼只核對一位學生與一門課；老師只能解除自己的課程 | 必做 |
| 麥克風 | 使用者不知情錄音 | 明確開始／停止、權限提示、播放確認及送出；不自動背景錄音 | 必做 |
| 檔案上傳 | 惡意／過大檔案與錯誤格式 | 驗實際內容、大小、類型、歸屬；限制解析時間／資源 | 必做 |
| 音檔／MIDI 下載 | 私人網址外洩 | 權限檢查後才能讀取，禁止永久公開學生錄音網址 | 必做 |
| 錄音辨識 | 低信心誤判學生 | 分析不確定明示；失敗不當 0 分；保留參考與版本 | 必做 |
| 課前摘要 | 跨老師取數／LLM 編造 | 後端固定窗口與授權，保留來源；無紀錄不推論沒練 | 必做 |
| 摘要時效 | 新練習被舊摘要忽略 | 來源指紋／課堂版本比對，標記需要更新及生成時間 | 必做 |
| AI Prompt | 教材或文字注入、個資外傳 | 資料當非指令處理、固定輸出格式、最小必要資料，不給任意 DB／工具權限 | 必做 |
| AI 費用 | 匿名推薦／錄音／出題濫用 | 帳號／IP 限流、檔案長度與生成上限、重試上限與用量記錄 | 必做 |
| 課務異動 | 重複更新或改錯課 | 必要同意、版本檢查、時段衝突檢查與交易回滾 | 必做 |
| 聊天 | 錯收件人／未讀不一致 | 成員驗證、有效關係、送出識別碼去重、受控讀取游標 | 必做 |
| AI 測驗 | 題目偏離教材、未審核發布、答案提前外洩或越權看結果 | 題目只來自老師提供的內容；AI 只產生草稿；老師審核後發布；交卷前不回傳答案或解析；學生只讀自己的結果 | 必做 |
| Secret | 金鑰外洩 | 環境變數／既有 Secret 管理；不進前端、Git 或 Log | 必做 |
| 傳輸及登入憑證 | 憑證外洩或請求偽造 | HTTPS；依現有 cookie／token 模式落實相應 CSRF、CORS 與安全設定 | 必做 |
| 稽核 | 無法追查確認與發布 | 操作者、時間、目標與結果；敏感值遮罩、一般使用者不可改 | 必做 |
| 備份 | 失去教學歷史／參考答案 | DB 與檔案有一致備份策略，驗證還原 | 必做 |
| 保留／刪除 | 個資長期堆積 | 明示用途、保存期限與刪除政策；正式期限待定 | 必做 |

## 2. 目前實作狀況（依 `main` 程式）

| 項目 | 現況 |
| --- | --- |
| 登入限流 | 沒有。只有設定共用本機模型時，首頁推薦有單程序記憶體內的限流 |
| HTTPS 與 Cookie | 本機是 HTTP。`SESSION_HTTPS_ONLY=true` 時 Session Cookie 只走 HTTPS，共用測試站（`render.yaml`）已設定 |
| 檔案上傳 | 都有大小上限（MIDI 2 MB、圖片 5 MB、錄音 20 MB、作業教材單檔 30 MB、證明文件 5 MB）。MIDI 與圖片會檢查檔頭，錄音只檢查副檔名。沒有惡意檔案掃描 |
| 檔案儲存 | 本機放 `uploads/`；共用測試站放 Supabase 私有 bucket，由後端檢查權限後提供 |
| 稽核 | 沒有獨立的操作稽核紀錄 |
| 備份 | 共用測試站有本機排程備份與隔離還原檢查（見 `docs/operations.md`）；本機資料庫用 `db-helper.sh` 手動備份 |
| 保留與刪除 | 正式期限未定 |
| AI 測驗 | 尚未完成，表內相關控制還沒有對應實作 |

## 3. 最低驗證

- A 老師不能查 B 老師所教學生的錄音／課前摘要，即使同學生在兩邊修課。
- 學生不能改 ID 取得他人錄音或接洽對話；未綁定不能讀課表、錄音、練習回饋與課前摘要。
- 公開課程與推薦 API 不含聯絡私密資訊、學生成績、錄音或課前摘要。
- 麥克風只在使用者明確操作及授權後錄音；不合法檔案不觸發無限分析。
- 無平台練習紀錄、分析失敗及低信心可區分；模型不編造分數或練習次數。
- 已發布 MIDI／題目不覆寫；摘要有來源與時間窗口。
- 重複提交／重試／交卷／審核不重複產生業務效果。
- 未經老師審核的測驗不能發布；作答回應不含答案；學生不能讀取他人的測驗結果。
- 日誌及版本控制無金鑰／Token／密碼；備份能還原。

## 4. 從 V1.1 移除的運作控制

本版無 LINE 登入身份、Webhook 簽章、Push、人工路由／24 小時接管或 LINE 顯示名稱控制。移除功能入口與執行依賴；若已有歷史 LINE 資料須另盤點遷移與保留，不由本文件直接刪除。
