# 鋼琴教學管理與課程推廣平台 SRS

版本 V1.3；更新 2026-10-12；需求依據 PRD V1.3。正式畫面使用 Vue，後端使用 FastAPI，資料庫使用 PostgreSQL。

## 1. 功能需求與驗收

| ID | 系統必須提供 | 驗收重點 |
| --- | --- | --- |
| AUTH-01 | 沿用師生註冊、登入、登出、基本資料與單一角色 | 不重做登入；學生不能呼叫老師的課程管理 |
| AUTH-02 | 平台管理員審核老師 | 管理員只能由系統依 `.env` 建立 |
| CAT-01 | 已發布課程可被訪客查看 | 草稿與已封存課程不出現在推薦與洽詢 |
| CAT-02 | 老師管理自己的課程 | 可填程度、風格、線上或實體、地區、單堂價格、時段；狀態只有草稿、已發布、已封存 |
| REC-01 | 訪客免登入描述需求 | 只處理鋼琴；未知條件不視為符合 |
| REC-02 | 找課程度與追問 | 入門、初階、中階、進階、不確定；整次最多兩題；不用練習分數 |
| REC-03 | 推薦結果 | 只回傳資料庫中的已發布課程；沒有符合項目時明確說明 |
| INQ-01 | 註冊學生按洽詢建立接洽對話 | 不另填申請表；同一學生可同時有多段對話，每段只屬一門課 |
| BIND-01 | 老師產生綁定碼並貼進該對話 | 一碼只給一位學生的一門課；不寄信、不簡訊 |
| BIND-02 | 學生輸入綁定碼 | 只進入該課程；原本對話保留 |
| BIND-03 | 老師解除自己課程的綁定 | 該課教學功能關閉；對話保留；其他課程不受影響 |
| SCH-01 | 已綁定學生查看該課課表 | 未綁定學生不能查看 |
| CHG-01 | 約課、請假、調課 | 老師同意且時段未被占用前，正式課表不變 |
| CHAT-01 | 接洽對話的歷史、未讀與新訊息 | 綁定前後是同一段對話；留在頁面時看得到新訊息 |
| FILE-01 | 受保護的參考 MIDI 與練習錄音 | 檢查歸屬；不把學生錄音做成永久公開網址 |
| PRA-01 | 每門課一份參考 MIDI | 已綁定學生的練習針對這份曲子 |
| PRA-02 | 瀏覽器錄音，無麥克風可上傳音檔 | 可回聽後再送出；只能送出自己的練習 |
| PRA-03 | 音高與節奏分開計算 | 辨識失敗不顯示成 0 分 |
| PRA-04 | 該次練習回饋 | 含音高、節奏與文字；文字只依該次評分結果 |
| PRE-01 | 課前摘要 | 同一學生、同一課程；上一堂結束後到這一堂開始前 |
| PRE-02 | 摘要與單次回饋分開 | 無平台紀錄時不說成沒有練習；不合成正式程度 |
| UI-01 | Vue 正式流程與 Jinja 測試頁 | 新 API 都有簡單測試頁；正式使用者只走 Vue |

## 2. 核心狀態

| 領域 | 狀態及規則 |
| --- | --- |
| 課程 | 草稿、已發布、已封存。只有已發布可推薦與洽詢 |
| 接洽對話 | 學生按洽詢後建立。綁定後繼續使用同一段 |
| 綁定 | 未綁定、已綁定。老師解除後回到未綁定，對話仍在 |
| 課務申請 | 送出後正式課表不變。老師同意且時段空著才更新課表 |
| 練習分析 | 待處理、處理中、完成、失敗。失敗不是 0 分 |
| 課前摘要 | 與練習回饋分開保存 |

## 3. 資料與 AI 邊界

找課程度與練習回饋分開。找課程度只來自自述。練習回饋只描述一筆錄音的音高、節奏與文字。課前摘要只彙整指定期間，不覆蓋找課程度。

音訊分析、規則計分與文字生成分開。AI 不取得任意資料庫寫入權限，不決定誰可以看資料，不直接改課表。

每筆要隔離的資料都要能辨識所屬老師與課程。不能只靠學生身分查詢。

## 4. 非功能需求

- 正式畫面用 Vue，以 JSON API 與 Session Cookie 登入。
- 本機 CORS 允許 Vue 開發網址帶 Cookie。
- 慢速音訊與文字生成不擋住課表操作。學生可再查詢已保存的處理狀態。
- 回饋延遲秒數等實際部署量測後再定，本輪不宣稱零延遲。
- `.env`、金鑰與密碼不放進映像檔或 Git。
- 正式環境 HTTPS、限流與 Session `https_only` 留到之後。

## 5. 核心驗證情境

1. 訪客描述模糊時最多補問兩題，只看到已發布鋼琴課。
2. 訪客沒有提供預算時，推薦不宣稱課程符合預算。
3. 學生按洽詢後可傳訊息，但不能打開課表、錄音、練習回饋或課前摘要。
4. 學生輸入別門課或別人的綁定碼時，不能進入課程。
5. 老師解除綁定後，該課教學功能關閉，對話還在，另一門課仍可使用。
6. 老師同意調課時目標時段已被占用，正式課表保持原狀。
7. 學生錄音後看到該次音高、節奏與文字；分析失敗時不是 0 分。
8. 老師看到的課前摘要只含該學生、該課、上一堂結束到這一堂開始前的練習。
9. 老師不能讀取其他老師課程中的學生、錄音、回饋、摘要與訊息。

本文件定義應有行為。上述測試尚未在本輪實作完成。

## 6. 本輪不做

教材上傳與閱讀、AI 測驗出題、審核、作答與批改。這些留到之後；屆時仍須遵守老師與課程隔離。
