| 項目 | 內容 |
| --- | --- |
| 版本 | V1.2 |

## 1. 目標

驗證角色與租戶隔離、核心課務狀態、即時聊天、AI 測驗與鋼琴回饋可安全整合，並確保失敗時不產生錯誤正式資料。

## 2. 測試層級

| 層級 | 重點 |
| --- | --- |
| Unit | Service 商業規則、排序、計分、狀態轉換、回饋降級 |
| Integration | API＋DB、Migration、檔案狀態、背景任務 |
| Contract | Request／Response、錯誤碼、AI Structured Output |
| E2E | 訪客、老師、學生完整流程 |
| Security | 角色、租戶、IDOR、WebSocket、上傳與 Prompt Injection |
| AI Evaluation | 推薦抽取、出題依據、鋼琴區段回饋與低信心處理 |

## 4. E2E 驗收旅程

### 4.1 公開課程

1. 訪客輸入「想學鋼琴，只會一點旋律」。
2. AI 最多追問 2 題。
3. 系統顯示真實有效課程與理由。
4. 訪客註冊學生並送出洽詢。
5. 老師接受後建立關係。

### 4.2 課務與聊天

1. 老師建立學生課堂。
2. 學生看到課表並提出調課。
3. 老師尚未核准前課表不變。
4. 老師核准後課表更新。
5. 雙方在同一對話即時傳送文字並看到未讀數。

### 4.3 AI 測驗

1. 老師上傳教材並產生題目草稿。
2. 老師修改答案、完成審核並發布。
3. 指派學生後，學生作答並提交。
4. 系統依核准答案自動計分。

### 4.4 鋼琴練習

1. 老師上傳測試樂譜圖片或參考音檔並指派。
2. 學生授權麥克風、錄音、播放並送出。
3. 分析完成後顯示小節／區段建議與信心。
4. 低信心資料顯示限制或要求重錄。

## 5. AI 評估指標

| 模組 | 指標 |
| --- | --- |
| 推薦 | 條件抽取 Precision／Recall、程度一致率、無效課程率 0% |
| QA | 有依據回答率、無答案時安全拒答率 |
| 測驗 | 教材依據正確率、老師接受率、錯誤答案率 |
| 鋼琴 | 區段對齊率、刻意錯誤召回率、誤報率、低信心降級正確率 |

## 6. Test Data

- 使用合成帳號、假工作室與假學生資料。
- 建立 A／B 工作室隔離測試 Fixtures。
- 教材使用自有、授權或測試內容。
- 鋼琴固定曲目需建立：標準版、節奏偏慢版、錯音版、雜音版。
- 不將真實學生個資、聊天、教材或錄音提交 Git。
