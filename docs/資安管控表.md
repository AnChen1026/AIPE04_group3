# 個人工作室智慧管理平台－資安管控表

| 項目 | 內容 |
| --- | --- |
| 版本 | V1.2 |
| 適用階段 | MVP |
| 最後更新 | 2026-09-24 |

## 1. 管控原則

1. 前端傳來的角色、`studio_id`、`student_id` 與資源 ID 都不視為授權證據。
2. AI 只能理解、生成草稿與說明；權限、候選課程、課表異動與計分由後端控制。
3. 音訊、樂譜與教材屬使用者檔案，採最少蒐集、權限隔離與明確保留期限。
4. 即時聊天須先保存、再推送，並在每次連線與訊息操作驗證成員資格。
5. Secret 不進程式碼、前端、Git 或一般 Log。

## 2. 管控建議

| 管控項目 | 主要風險 | MVP 作法 | 優先級 |
| --- | --- | --- | --- |
| 密碼與登入 | 帳號接管 | Argon2id／bcrypt 等成熟雜湊、登入限流、重設憑證限時一次性 | 必做 |
| Session／Token | Token 遭竊或長期有效 | HttpOnly、Secure、SameSite Cookie 或受控 Token；短效與撤銷策略 | 必做 |
| 固定角色 | 學生竄改為老師 | 角色由後端資料庫取得；角色變更限管理流程並稽核 | 必做 |
| 多租戶授權 | 跨工作室讀取 | Service／Repository 同時限制資源 ID 與授權 `studio_id` | 必做 |
| API 輸入 | 注入、越權與非法狀態 | Pydantic、ORM／參數化查詢、後端狀態轉換驗證 | 必做 |
| 邀請碼／連結 | 被猜測、轉傳或重放 | 高熵隨機值、只存雜湊、限時限次、可撤銷、接受時二次確認 | 必做 |
| 課程洽詢 | 冒名建立關係 | 必須登入學生帳號；老師接受後才建立正式關係 | 必做 |
| 課務異動 | 重送或 AI 直接改課 | 老師確認、冪等鍵、樂觀鎖、資料庫交易與稽核 | 必做 |
| WebSocket 驗證 | 竊聽其他對話 | 連線、訂閱、發送三階段皆驗證登入與 conversation membership | 必做 |
| 聊天越權 | 猜 ID 讀取歷史 | 查詢固定帶入目前 user_id；禁止僅依 conversation_id 查詢 | 必做 |
| 訊息重送 | 重複內容／未讀錯誤 | client_message_id 唯一、伺服器 message_id、已讀位置單調前進 | 必做 |
| XSS | 聊天內容執行腳本 | 純文字顯示、輸出轉義、CSP；MVP 不接受 HTML | 必做 |
| 教材上傳 | 惡意檔案與成本濫用 | 副檔名＋MIME＋檔頭檢查、大小限制、病毒掃描、Rate Limit | 必做 |
| 樂譜／音訊上傳 | 未授權存取 | 私有物件儲存、短效簽名 URL、ownership 與用途檢查 | 必做 |
| 麥克風 | 未經同意錄音 | 只在明確操作後請求權限；錄音狀態持續可見；提供停止與刪除 | 必做 |
| AI 教材出題 | Prompt Injection／越權取檔 | 只提供指定教材內容、固定 Schema、工具白名單、忽略教材中的指令文字 | 必做 |
| AI 推薦 | 生成不存在課程 | 後端建立候選；AI 只能說明候選，不得自由產生 course_id | 必做 |
| AI 練習回饋 | 錯誤斷言傷害信任 | 信心門檻、降級回饋、禁止精密斷言、標示僅供練習參考 | 必做 |
| 個人資料 | 姓名、學習與聊天外洩 | 最小化、欄位遮罩、最小權限、保留期限與刪除流程 | 必做 |
| Secret | API Key 外洩 | 環境變數／Secret Manager；`.env` 不提交；Log 過濾 | 必做 |
| 錯誤訊息 | 洩漏系統內部資訊 | 對外統一錯誤碼與 request_id；詳細錯誤進受控 Log | 必做 |
| 稽核 | 爭議無法追查 | 登入、角色、邀請、關係、異動、發布、檔案與管理操作留紀錄 | 必做 |
| 依賴與映像 | 已知漏洞 | 鎖定版本、依賴與容器掃描、定期更新 | 建議 |
| 管理員 | 高權限濫用 | 與一般角色分離、MFA、高風險操作填原因 | 建議 |
| 備份 | 誤刪／故障 | 自動備份、限制備份權限、至少一次還原演練 | 必做 |

## 3. 資料分類與保留建議

| 資料 | 分類 | 初步保留建議 |
| --- | --- | --- |
| 公開課程 | Public | 上架期間及必要歷史 |
| 帳號與師生關係 | Personal | 關係存續期間＋依法或營運需要 |
| 聊天內容 | Personal | 180 天，可由政策調整 |
| AI 客服原始對談 | Personal | 匿名 30 天、登入者 90 天；MVP 不建立長期推薦檔案 |
| 教材與樂譜 | Personal／Copyright | 任務有效期間，刪除後依備份週期清除 |
| 學生錄音 | Sensitive Personal | 90 天或老師／學生主動刪除，以較早者為原則 |
| 鋼琴分析結果 | Personal | 180 天，模型評估資料需另行取得同意 |
| 測驗作答 | Personal | 課程期間＋1 年，正式期限待團隊確認 |
| 稽核紀錄 | Audit | 至少 1 年，正式期限待確認 |

以上為工程建議，不取代正式法律意見。

## 4. 上線前最低檢查

- [ ] `.env`、Token、API Key、Database URL 未提交。
- [ ] 學生無法呼叫老師／管理員 API。
- [ ] A 工作室無法讀取 B 工作室課程後台、學生、聊天、教材或錄音。
- [ ] 過期、撤銷、重放邀請不會建立關係。
- [ ] 未經老師確認，學生申請不會修改正式課表。
- [ ] 非對話成員無法連線、訂閱、讀取或發送訊息。
- [ ] 聊天文字以純文字安全顯示，不執行 HTML／Script。
- [ ] 上傳檔案類型、大小、檔頭、掃描與權限均有驗證。
- [ ] 麥克風未授權時不錄音，錄音中有持續可見提示。
- [ ] AI 題目未經老師發布，學生無法作答。
- [ ] AI 無法自行指定任意 course_id、student_id 或 studio_id 存取資料。
- [ ] 低信心鋼琴分析不輸出精密或保證性結論。
- [ ] Log 不包含密碼、Token、完整錄音內容或不必要聊天內容。
- [ ] 資料庫及物件儲存備份可還原。
