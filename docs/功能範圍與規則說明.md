# 鋼琴教學管理與課程推廣平台－功能範圍與規則

更新 2026-11-01，依 `main` 的程式現況；配套：PRD、SRS、User Flow。

## 1. 已定方向

網站只做鋼琴。正式畫面使用 Vue，後端使用 FastAPI，資料庫使用 PostgreSQL。登入沿用 Session Cookie，不改成 JWT，也不改成 Next.js。

## 3. 必須對齊的規則

- 洽詢只建立接洽對話。輸入綁定碼後才使用課表、錄音、練習回饋、課前摘要與課程管理。
- 綁定前後是同一段對話。
- 綁定碼只屬於一位學生的一門課。限時綁定碼屬於一門課，期限內可重複使用，同時只有一組。
- 約課和調課只能從可上課時段選；老師同意且時段未被占用前，正式課表不變。
- 練習回饋與課前摘要分開保存。
- 找課程度不使用練習分數。
- 老師只能讀取自己課程的資料。
- AI 只能產生測驗草稿，不能自行發布；作答中不能回傳正確答案。
- 使用者只走 Vue。新 API 不另做測試頁，以 `/docs` 與 `tests/` 自動測試驗證。

## 4. 尚未定的參數

錄音長度上限、評分容許誤差、回饋延遲秒數與資料保留期限尚未定。錄音檔案大小上限目前是 20 MB。
